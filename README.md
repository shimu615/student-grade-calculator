# Student Grade Calculator

Built with Shimu

A beginner-friendly project using HTML, CSS and vanilla JavaScript.

## Features
- Student name and ID
- Five subject marks
- Automatic total, average, percentage, grade and GPA
- Pass/fail status (minimum 33 in each subject)
- Save, delete and export student records to CSV
- Responsive layout
- Browser localStorage

## Run
Open `index.html` in your browser. No server or package installation is required.

## Grading note
The grade thresholds are illustrative examples, not an official university grading policy. Edit `getGrade()` in `js/app.js` to match your institution.

## Storage note
Records stay in the current browser on this device. Clearing browser site data may erase them.
